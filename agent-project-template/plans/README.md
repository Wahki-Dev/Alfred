# agent-project/plans/

Un fichier par feature, écrit avant le code (`agent/rules/workflow.md` §2), sur le modèle
`agent/session/doc-templates/plan.md`.

- Nommage : `AAAA-MM-JJ-HHMM-slug.md` (ex : `2026-06-25-1530-export-csv-factures.md`) ; le plus récent est le dernier.
- Avancement : les cases à cocher de la section « Étapes » ; statut dans le front-matter
  (`brouillon`, `en_cours`, `terminé`, `abandonné`).
- Reprise : « reprends le plan export-csv-factures » → l'agent repart de la première étape non cochée.
- Pas de plan en parcours rapide.
