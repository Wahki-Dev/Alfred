# agent-project/plans/

Plans de feature validés — 1 fichier par feature.

- Écrit en PLAN MODE (`agent/rules/workflow.md` §1), revue incluse dans la même étape, à partir du template
  `agent/session/doc-templates/plan.md`.
- Absent en parcours rapide (§0ter) : pas de fichier plan.
- Nommage : `AAAA-MM-JJ-HHMM-slug.md` (horodatage de création + slug court).
  - ex : `2026-06-25-1530-export-csv-factures.md`
  - tri alphabétique croissant : le plan le plus récent est le **dernier** de la liste.
- Spécifique au projet, non copié d'un projet à l'autre.
- Contrôlé à l'audit final (`workflow.md` §8) : couverture complète + aucun écart non justifié.
