# Template — Génération de agent-project/cdc.md

> Ce fichier explique à l'IA COMMENT générer `agent-project/cdc.md` pour un nouveau projet.

---

## Processus de création

### Étape 1 — Cadrage

Explorer ou demander :
- Le problème à résoudre
- Les utilisateurs / rôles concernés
- Les objectifs indispensables
- Les non-objectifs
- Les règles métier connues
- Les contraintes légales, opérationnelles ou techniques

### Étape 2 — Rédiger le draft

Documenter uniquement les éléments validés ou observés.
Marquer les inconnues comme questions ouvertes.
Proposer le draft pour validation avant écriture.

---

---

## Règles de maintenance de cdc.md

- Taille cible : ≤ 200 lignes
- Garder un langage compréhensible par un non-technicien
- Ne pas dupliquer les conventions techniques de `memory.md`
- Mettre à jour quand le périmètre produit change
- Conserver les décisions non tranchées dans `Questions ouvertes`
